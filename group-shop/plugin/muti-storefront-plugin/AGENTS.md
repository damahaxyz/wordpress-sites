# muti-storefront-plugin 接手约定

继承根 AGENTS.md。先读 README、HANDOFF、ARCHITECTURE、CHANGELOG。当前 0.5.10 本地为单站多品牌，已关闭 Multisite，生产未发布；不得自动上线。

Brands 管业务范围，不再 switch_to_blog；get_current_blog_id 恒 1。公共商品不直接销售，品牌原生版本独立成交、上架、评论和订单。共享分类、标签及媒体，私有集合／菜单／页面必须标品牌。客户同邮箱多 ID，角色固定；员工显式授权，品牌 Administrator 不等于总管理员。

原生编辑器／列表优先扩展。中央仅保留概览／品牌设置／商品集合／日志／文档五标签；不恢复退休的订单／评论／客户／主商品发布标签及旧跨站发布、媒体导入、词表同步、用户拆分写入 API。用户最新授权的公共档案和品牌覆盖使用 ProductVersions 原生面板。

每次变化同轮更新文档、CHANGELOG、HANDOFF及真实测试。新测试仅 local＋.local＋私有 fixture，严禁生产。不要在日志／报告展示密码、重置链接、令牌、SMTP 凭据或完整地址。Woo CRUD／HPOS、nonce、完整表单标记、上下文恢复和业务数据保留规则不可省略。

集合仍按品牌持久规则、原生成员、动态区块／短代码／主题接口及经典 Shop 过滤；不得把空失效条件变全商品，不得自动套用到独立 Store API 集合筛选区块。商品与变体统一原生Products编辑，差异与品牌权限校验不能省略。未知第三方插件与真实支付／退款不宣称自动兼容。

0.5.1 本地：原生 Products 筛选／来源／版本导航与状态计数已完善。继承字段只在启用覆盖时显示，公共字段和变体结构在公共档案维护；服务端保存前也恢复继承。继承商品不再使用旧简化编辑器，品牌商品标签／列表仍保留，独立商品原简化编辑有效。不要恢复继承行的无效快速／混合批量编辑或重复表单。

- 2026-11-05，0.5.2 本地：原生 Products 提供批量继承公共商品为指定品牌草稿、批量上架／转草稿；继承仅总管理员，状态逐商品校验授权。确认目标、最多200父商品、单件请求、24小时私有任务与暂停／重试；已有版本（含回收站）不得覆盖或重复创建。不得恢复旧发布标签或自动部署。

0.5.3 最新决定覆盖旧独立商品方案：统一公共档案＋必有关联的品牌版本，Products 合并为公共／品牌单筛选，root默认公共。员工只管理获授权版本，不创建公共商品或独立商品。归属／来源固定，只允许显式差异覆盖；所有品牌编辑统一原生，旧独立简化编辑器已移除。

0.5.4：中央品牌商品标签及ProductAdmin／Catalog旧商品写入服务已删除，旧GET引导原生（缺省公共／指定品牌／具体商品），旧写入410拒绝。用户新增要求评估商品集合，当前只给方案，不改集合实现。

0.5.5：用户已授权分类列表共享／店铺切换与集合parent层级。原生Categories默认共享；各店只显示所属集合，集合完整编辑／回收仍在CollectionAdmin。父级只准同店未删除集合，禁止成环和共享／跨店父级；各集合成员独立，不自动汇总子集合。新增集合必须写品牌标记；全局分类层级缓存查询不能按品牌裁切。保留ID／slug，改变parent会改变原生层级URL。详见最新HANDOFF与v055本地验收；禁止自动部署。

- 2026-11-05，0.5.6 最新页面决定：只按店铺区分原生Pages，不需要模板继承。不得引入公共页面模板、模板同步／品牌变量或新的用途绑定层。原生页面独立编辑与发布，默认主店、可切店，归属固定、parent同店无环；隐私／条款原设置和页脚保持。仍仅本地测试，不部署。

- 2026-11-05，0.5.7 菜单决定：原生Menus按店铺切换、默认主店，菜单／位置／auto_add独立。商品只选本站销售版本，页面／文章／启用集合只选本站，共享分类／标签继续共用；自定义链接限本站。品牌Administrator只获受控菜单入口，不扩大全局主题权限，Shop Manager保持。服务器先验证完整原生／AJAX请求再写入，Customizer菜单与菜单REST编辑关闭。Footer绑定生效，未绑定保留旧链接；新店不复制主店菜单，仅本地验证，不部署。

- 2026-11-05 最新本地数据基线：用户本轮明确授权清空业务、保留七品牌／后台账号／配置，并仅导入CSV公共商品。已完成72公共商品、72本地图、349属性，0品牌版本／顾客／订单／页面／菜单／集合；保留2后台身份，旧档案业务行也已清空但表结构保留。私有成套备份见OPERATIONS，源CSV未改、无生产连接。旧718项保留检查及旧fixture编号是历史，禁止直接重跑旧清理或据此恢复旧数据。这是一次性清空授权，不是未来自动重置许可；软件仍0.5.7。

- 2026-11-05，0.5.8 最新决定：保留add-ons，各店独立配置，只关联同店销售商品／变体，不继承公共规则。保存／加购／重算／订单行均校验，失效规则移除旧子项并提示，不用旧快照价；保留迷你购物车普通数量功能。Product presentation动态继承公共字段，勾选本店单独设置才覆盖，取消恢复；自动订单数仍按店。Trovesia本地3.8.4，无业务数据自动迁移。当前开始时72公共＋72品牌商品，保护用户新建版本，不能按重置后的旧0版本基线清理。仅本地，不部署。


- 2026-11-06，0.5.9 SEO决定：仅隔离页面／文章、销售商品／变体、分类统计与私有集合、菜单及SEO业务入口，CSS／JS／图片和wp-content素材共用。普通分类／标签词条仍共享。SeoIsolation校验ID／Store API slug／评论／集合，分类响应及聚合缓存按品牌；原生Sitemap与链接不得串店。禁止404猜测，保留验证归属后的本店旧slug301；正文外店业务链接／iframe只在渲染时移除href／src，不重写数据库。46运行＋315 HTTP检查通过，合成资料清理与八表／七品牌业务配置保留，仍72公共＋72主店版本。仅本地，禁止部署；第三方SEO／接口及Woo升级需专项复验。


- 2026-11-06，0.5.10更名：本插件目录／入口／显示名统一muti-storefront-plugin，附加插件为product-addon-plugin 3.8.5；保留GSM／GroupShop、TROVESIA／Trovesia及业务数据键／接口，后台旧slug为受控隐藏兼容跳转。trovesia-channel本地禁用且源码保留，默认页脚入口按实际加载状态隐藏。QA私有目录／项目／脚本分组仍group-shop-manager-qa／group-shop-manager，不创建新数据库卷或重跑旧安装器。27运行／数据＋43 HTTP检查通过，九表哈希及用户资料／权限／会话与七品牌业务配置保留，测试登录仅正常更新wc_last_active活动日期；未发布生产。
