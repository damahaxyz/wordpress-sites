# 0.4.0 多店用户模块本地验收

2026-11-04，Asia/Taipei。源码 0.4.0，仅本机合成 QA；未连接生产、未部署。保持现有七个 HTTP .local 域名、只读代码挂载与邮件／支付拦截。测试环境 WordPress 7.0.4、PHP 8.3、WooCommerce 11.1.2、FluentSMTP 2.4.1。

## 实际行为

顾客 A／B 分别为不同原生用户，可见用户名和真实邮箱相同，密码／默认地址／Cookie 会话独立；未注册店铺拒绝登录。员工为单独共享身份，只有网络超级管理员可在原生资料页设置各店 Administrator／Shop Manager，新员工和新店无自动授权。顾客固定 Customer，不能通过角色表单、超级管理员 API、成员 API、metadata 或 REST 转员工／跨店加入。后台登录优先员工，前台优先本店顾客，无自动 SSO。

继续复用原生网络／各店用户管理；列表新增类型／范围及可见用户名，原生 Username 保留内部唯一标识。原生邮箱确认只可关联本店顾客的本店历史游客订单；在网络主店编辑异店顾客／员工时禁用该控件，伪造字段也忽略。

## 兼容边界

同一个 Multisite 数据库内的逻辑隔离，网络超级管理员仍能管理全网；没有物理分库或自动 SSO。原生真实邮箱可以跨 ID 重复，第三方全局 get_user_by('email')／自定义 SSO／会员和资料导出插件需单独接入本店索引；不承诺未知插件自动兼容。测试只覆盖当前插件组合。旧 v036 共享用户套件及已退休的商品发布 fixture 不适用于当前版本。生产迁移必须等新的用户发布通知，再按实际环境备份／预检／维护窗口执行。
