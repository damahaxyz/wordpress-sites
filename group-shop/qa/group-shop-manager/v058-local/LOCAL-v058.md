# 0.5.8 商品展示与独立加购本地验收

2026-11-05，Asia/Taipei。Group Shop Manager 0.5.8／Trovesia Plugin 3.8.4，单站七品牌，严格.local loopback；无生产连接或部署，邮件／支付MU拦截保持。

用户最终决定保留add-ons并按评估改造，同时让Product presentation支持公共继承。未删除加购模块、普通迷你购物车数量接口或独立订单行。

## 行为

- 展示文案默认从 `_gsm_base_product` 对应公共商品动态解析；`_gsm_overrides` 的presentation项开启时读取本店字段。五个可见字段和原有配送天数元数据同组处理，公共更新即时生效，无批量复制／迁移。单独设置为空时保留既有默认文案或本店自动统计。
- 公共商品add-ons面板说明配置入口，品牌面板只列本店其他简单商品／具体变体；不继承公共规则。最多20条，完整标记／条数／字段与nonce／对象权限在原生写标题前检查，元数据写入另有同店保护。
- 加购、重算及订单行检查真实父项、子商品／变体、规则及店铺关系。换绑、删除或失效时移除旧子项并提示重选，不用旧快照价兜底；子项不触发嵌套自动加购。保留跟随价／固定价／百分比折扣、数量及移除联动；对购物车子商品对象克隆后改价，避免污染同商品普通行。
- 订单活动数显式按店查询，缓存键也带品牌ID，避免共享缓存复用别店统计。继承的是自定义提示文字，自动订单量不继承。

## 边界与复验

当前支持原生经典商品编辑与经典商品页选择加购；Store API已有购物车读写继续触发重算保护。未新增区块商品页加购选择器，不宣称第三方编辑器／购物车／订阅兼容。展示继承通过支持的字段读取解析；原始本地meta仍保留，原始数据库导出不是展示的最终生效值。公共自定义信息不自动引入店铺变量或政策模板。

只使用本轮新私有清单。顺序：product-experience-v058.php → check-product-experience-v058-local.py → 浏览器 → cleanup-product-experience-v058.php；另运行order-activity-v058.php，其自带订单清理。fixture已清理，重跑必须新建，禁止拿旧迁移／清空基线的编号删除当前业务商品。当前商品基线72公共＋72品牌，早期718项历史保留检查不适用于重置后的环境。
