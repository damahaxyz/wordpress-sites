# Group Shop 工作约定

先读 plugin/group-shop-manager/README.md、docs/HANDOFF.md、docs/ARCHITECTURE.md、CHANGELOG.md。涉及运维再读 docs/OPERATIONS.md 和根 DEPLOYMENT.md。根 PROJECT-HANDOFF.md 是复制来的 Trovesia 历史材料，不是本插件规格。

## 当前产品决定（2026-11-06，0.5.9 本地）

- 用户明确要求一套商城、多个品牌门面，关闭 Multisite。当前本地已经迁移为单站，覆盖历史必须 Multisite、按站词表投影及共享顾客方案。历史行为仅看 CHANGELOG 与 qa 版本记录，不得恢复旧语义。
- **后续改动只在本地测试，等用户明确新通知再发布。禁止自动部署、连接生产转换或在线清理。** 当前七个 HTTP .local 域名均 loopback；旧 localhost 安装器／fixture 不可去掉保护用于当前环境。
- 公共原生商品档案＋原生品牌销售版本，标题、长短描述、图片及售价可显式覆盖，取消即继承；分类／标签／媒体共用。品牌集合、发布状态、排序、评论、顾客、订单归属独立。
- 顾客按品牌使用不同原生 ID，可同可见用户名／真实邮箱；密码、默认地址、会话独立。Customer 类型固定，不得直接转员工。员工为独立共享身份，由商城总管理员逐品牌授权，无自动 SSO。
- 品牌 Administrator 只拥有受控本品牌经营／内容权限，不拥有全局插件／设置／主题／跨品牌报表权限。平台管理员由受控 ID 配置认定，不用单站 is_super_admin 判断。
- 原生后台优先扩展；不恢复统一订单、独立评论、共享客户、主商品发布标签。最新授权的公共档案在原生 Woo 面板管理，不恢复旧 Multisite 发布器／图片导入器。
- 全部商品／变体不管理库存、始终有货，保留独立草稿／上架状态。支付服务商、退款和自动 SSO 不开发；本地邮件／支付 MU 拦截保留。
- 一套商城共用主题代码、货币、税务、运费及网关配置。Logo、页面、菜单、集合和品牌展示选项按品牌读取。新品牌 noindex、mail off，无自动员工授权。

## 代码与验证边界

新业务位于 plugin/group-shop-manager/；禁止顺带修改独立 trovesia-shop 或其他项目。WooCommerce 使用 CRUD 并兼容 HPOS，分类／媒体／用户沿用原生 API。Brands::id 是品牌，原生 blog_id 恒 1；跨品牌受信操作必须 finally 恢复作用域，不能直接切原生表。外部选择品牌必须校验身份、归属及 nonce，不把数字 ID 当作授权。

不要记录密码、令牌、邮件正文、完整顾客地址或 SMTP 凭据。真实邮箱可重复，第三方全局邮箱取用户需本品牌适配。停用／卸载保留业务数据；不删除旧子站档案表或文件。回滚必须数据库、源码及配置成套恢复。

任何功能、数据、配置、权限、限制或运维变更，必须同轮同步相应文档、CHANGELOG 和 HANDOFF，记录真实测试结果；不得把计划记为完成或本地记为上线。测试只用本地合成资料，重跑先看脚本保护和 fixture 副作用；旧 .4 及以前 Multisite 套件只代表历史。

- 2026-11-05，0.5.1 本地：原生 Products 已补品牌／资料类型／公共来源／版本导航和状态计数；继承商品仅显示生效的编辑字段，公共字段／规格在公共档案维护。品牌商品标签暂保留，继承编辑统一到原生页，独立简化编辑保留。服务器仍必须恢复继承与校验对象权限。

- 2026-11-05，0.5.2 本地：原生 Products 提供批量继承公共商品为指定品牌草稿、批量上架／转草稿；继承仅总管理员，状态逐商品校验授权。确认目标、最多200父商品、单件请求、24小时私有任务与暂停／重试；已有版本（含回收站）不得覆盖或重复创建。不得恢复旧发布标签或自动部署。

- 2026-11-05，0.5.3 本地：取消独立品牌商品，所有品牌商品必须继承公共档案。总管理员 Products 单一归属筛选（公共／各品牌），无显式品牌时默认公共，不使用上次品牌Cookie；员工仅授权品牌。新建仅总管理员建立公共商品，现有品牌归属／公共来源固定，仍保留五组差异覆盖；品牌特有商品也先公共再继承，不能恢复独立商品／简化编辑器。

- 2026-11-05，0.5.4 本地：用户明确移除中央“品牌商品”标签及重复列表／编辑／状态操作。中央仅五标签，商品统一原生Products；旧GET安全跳转，旧edition_save／edition_status写入410拒绝，不能恢复Catalog／ProductAdmin。集合本轮仅评估，不改规则、存储或数据。

- 2026-11-05，0.5.5 本地：原生Categories默认共享，支持按店铺只查看对应集合；集合支持同店parent多级关系，服务端阻止循环／共享分类／跨店父级。层级组织与选品独立，子集合不自动计入父集合。ID与slug保留，原生归档URL随层级变化；仅本地验收，无部署。

- 2026-11-05，0.5.6 最新页面决定：只按店铺区分原生Pages，不需要模板继承。不得引入公共页面模板、模板同步／品牌变量或新的用途绑定层。原生页面独立编辑与发布，默认主店、可切店，归属固定、parent同店无环；隐私／条款原设置和页脚保持。仍仅本地测试，不部署。

- 2026-11-05，0.5.7 菜单决定：原生Menus按店铺切换、默认主店，菜单／位置／auto_add独立。商品只选本站销售版本，页面／文章／启用集合只选本站，共享分类／标签继续共用；自定义链接限本站。品牌Administrator只获受控菜单入口，不扩大全局主题权限，Shop Manager保持。服务器先验证完整原生／AJAX请求再写入，Customizer菜单与菜单REST编辑关闭。Footer绑定生效，未绑定保留旧链接；新店不复制主店菜单，仅本地验证，不部署。

- 2026-11-05 最新本地数据基线：用户本轮明确授权清空业务、保留七品牌／后台账号／配置，并仅导入CSV公共商品。已完成72公共商品、72本地图、349属性，0品牌版本／顾客／订单／页面／菜单／集合；保留2后台身份，旧档案业务行也已清空但表结构保留。私有成套备份见OPERATIONS，源CSV未改、无生产连接。旧718项保留检查及旧fixture编号是历史，禁止直接重跑旧清理或据此恢复旧数据。这是一次性清空授权，不是未来自动重置许可；软件仍0.5.7。

- 2026-11-05，0.5.8 最新决定：保留add-ons，各店独立配置，只关联同店销售商品／变体，不继承公共规则。保存／加购／重算／订单行均校验，失效规则移除旧子项并提示，不用旧快照价；保留迷你购物车普通数量功能。Product presentation动态继承公共字段，勾选本店单独设置才覆盖，取消恢复；自动订单数仍按店。Trovesia本地3.8.4，无业务数据自动迁移。当前开始时72公共＋72品牌商品，保护用户新建版本，不能按重置后的旧0版本基线清理。仅本地，不部署。


- 2026-11-06，0.5.9 SEO决定：仅隔离页面／文章、销售商品／变体、分类统计与私有集合、菜单及SEO业务入口，CSS／JS／图片和wp-content素材共用。普通分类／标签词条仍共享。SeoIsolation校验ID／Store API slug／评论／集合，分类响应及聚合缓存按品牌；原生Sitemap与链接不得串店。禁止404猜测，保留验证归属后的本店旧slug301；正文外店业务链接／iframe只在渲染时移除href／src，不重写数据库。46运行＋315 HTTP检查通过，合成资料清理与八表／七品牌业务配置保留，仍72公共＋72主店版本。仅本地，禁止部署；第三方SEO／接口及Woo升级需专项复验。
