# Trovesia Shop Theme

This is the site-specific presentation layer for `trovesia-shop`.

- Edit `front-page.php` to change the storefront landing-page structure.
- Edit `header.php` and `footer.php` to change global navigation and footer content.
- Edit `style.css` for the visual system and responsive layout.
- Edit `assets/css/woocommerce.css` for product, catalogue, cart, and checkout styling.
- Add business rules and persistent features to `trovesia-plugin`, not to this theme.

The theme supports custom logos, navigation menus, featured images, the block editor,
and WooCommerce product galleries.
