# Trovesia Shop Theme

This is the site-specific presentation layer for `trovesia-shop`, redesigned
around the useful parts of the Viorine storefront without its cluttered urgency
patterns or misleading stock counters.

- Edit `front-page.php` to change the storefront landing-page structure and
  botanical hair-care story.
- Edit `header.php` and `footer.php` to change global navigation and footer content.
- Edit `style.css` for the visual system and responsive layout.
- Edit `assets/css/woocommerce.css` for product, catalogue, cart, and checkout styling.
- Add business rules and persistent features to `trovesia-plugin`, not to this theme.

The theme supports custom logos, navigation menus, featured images, the block
editor, WooCommerce product galleries, responsive product cards, cart and
checkout screens, and the Trovesia plugin's tracking/contact/product components.
