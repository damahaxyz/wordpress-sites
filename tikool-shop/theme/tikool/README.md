# Tikool Shop Theme

This theme is the Tikool presentation layer for custom pet portraits, gifts, and memorial keepsakes. `front-page.php` contains the homepage story; `homepage-banner.php` and `homepage-products.php` make its hero and product section editable in WordPress; `assets/css/woocommerce.css` styles product, cart, and checkout pages.

Persistent checkout, personalization, and order rules belong in `tikool-plugin`, not the theme.
